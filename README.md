# My Interactive Portfolio

This is a Next.js (App Router) portfolio site built with Tailwind CSS. It showcases my skills in digital marketing, graphic design, AI tools, and productivity solutions.

## Development

```bash
# Install dependencies
npm install

# Run locally
npm run dev
```

Open http://localhost:3000 to view the site.

## Deployment (Netlify)

The site is configured to deploy on Netlify using the `netlify.toml` file. Netlify will run `npm run build` and publish the `.next` directory.

1. Connect this repository to Netlify.
2. Ensure the build command is `npm run build` and the publish directory is `.next`.
3. Enable the **Next.js** plugin (automatically added via `netlify.toml`).

Once deployed, your portfolio will be available at the Netlify site URL, or at a custom domain if configured.
